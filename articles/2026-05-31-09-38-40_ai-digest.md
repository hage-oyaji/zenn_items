# AI主要サービスダイジェスト 2026-05-31 ─ 競争軸が「賢さ」から「任せ方」へ

ここ3週間のAI界隈を眺めていると、なんだか潮目が変わったな、と感じるんですよね。少し前までは「どのモデルがベンチマークで何点取ったか」で盛り上がっていたのに、いまは「そのモデルに、どれだけ大きな仕事を、どれだけ安心して任せられるか」に話題の中心が移ってきました。新しいフラッグシップモデルが続々と出てきた一方で、本当に騒がれているのは「エージェントを何十個も同時に走らせる仕組み」だったりするんです。つまり主役が「賢さ」から「任せ方」へ静かにシフトしてきた、そんな空気が漂っているのが今(2026-05-31 時点)の状況だと見ています。

## いま、AIの勢力図はこうなっている

土台を作っているのは、やっぱり基盤モデルの3社です。汎用的な強さで一歩リードしているのが OpenAI で、ChatGPT は週9億人が使うほどの規模になりました。コーディングや「自律的に仕事を任せる」領域で存在感を見せているのが Claude(Anthropic)、そして画像・動画・音声まで含めた表現力の広さと、コストの安さで攻めているのが Google AI、という三者三様の構図ですね。この3社が出すモデルを「道具」として使い、開発者の手元で実際に動くプロダクトに仕立てているのが Cursor と GitHub Copilot という2社です。同じエンジンを積んでいても、乗り味はずいぶん違う、というのが面白いところなんです。

この3週間で各社がぶつけてきたものを並べてみると、共通のテーマが浮かび上がってきます。それを3つだけ挙げるなら、こんな感じです。

- **「賢さ」から「規模」へ** — Claude が出した Dynamic workflows は、最大1,000個のサブエージェントを背景で並列に動かす仕組みです。Bun というツールのコードを Zig から Rust へ約75万行・11日で移植し、テスト99.8%通過という実例まで添えてきました。
- **「席を離れても自走する」が当たり前に** — OpenAI の Codex は目標を渡すと数十時間ひとりで作業を続けるモードが標準になり(Goal Mode)、Windows 上でのコンピュータ操作にも対応しました。
- **「課金と旧機能の整理」が摩擦を生む** — GitHub Copilot の従量課金移行や、OpenAI が予告なく Canvas を消したことなど、便利さの裏で利用者の不満も噴き出した3週間でした。

## 基盤モデル3社のポートレート

この3社は、それぞれ「自分はどこで勝つか」をかなりはっきり決めにきています。同じ「賢いAI」でも、向いている方向が違うんですよね。順番に見ていきましょう。

### Claude ─ 「正直さ」と「規模」で勝負しにきた

Claude を出している Anthropic は、5月28日に新しいフラッグシップ **Opus 4.8** を投入しました。面白いのは、これを「ベンチマークの点数を上げる発表」ではなく「品質と正直さの発表」と位置づけたことなんです。実際、コーディング能力を測る SWE-Bench Pro では 64.3% から 69.2% へ伸び、コードの欠陥を見逃す割合がだいたい4分の1まで減ったと説明しています。料金は入力 $5 / 出力 $25(100万トークンあたり)で据え置き。そして同じ日に、冒頭でも触れた Dynamic workflows という「エージェントを大量に並列で走らせる」仕組みを研究プレビューとして出してきました。1回の会話では捌ききれない大規模なリファクタや移行を、丸ごと任せられる未来が見えてきた、というわけです。$65B(約650億ドル)規模の資金調達も同日に発表していて、勢いを感じます。

| 項目 | 内容 |
|---|---|
| フラッグシップ | Opus 4.8(2026-05-28、1M トークンの文脈長、入力 $5 / 出力 $25) |
| 主要スコア | SWE-Bench Pro 69.2%、コード欠陥の見逃し約1/4に低減 |
| 注目機能 | Dynamic workflows(最大1,000サブエージェント並列)、fast mode を $10/$50 へ3倍値下げ |

**強み**: コーディングと「自律的に仕事を任せる」領域での強さは頭ひとつ抜けています。新機能を出すときに、コミット時に脆弱性をチェックするプラグインなど安全装置をセットで出してくる「正直さ・信頼性」の打ち出し方も、業務で使う人には安心材料なんですよね。企業向けでは、データを社外に出さずにエージェントを動かせる仕組み(Self-hosted sandboxes と MCP tunnels)も整えてきました。

**弱み**: 一方で「正直、前のモデルとの体感差はそんなに大きくない」という声も出ていて、いわゆる"ベンチマーク疲れ"の空気もあります。Dynamic workflows も強力なぶんコストが膨らみやすく、人間の見張りがまだまだ必要な段階です。気になる方は、使う前に消費量の目安を確認しておくのがよさそうです。

### OpenAI ─ 「全部入り」で王座を守る

OpenAI は相変わらず「ひとつの契約で何でもこなせる」総合力で先頭を走っています。主力の **GPT-5.5**(開発コード名 "Spud")は汎用的な知能指標でトップ級、ChatGPT は週9億人、コーディング特化の Codex も週400万人以上が使う規模です。この3週間で目立ったのは、Codex の「自走モード」が一気に成熟したことなんです。目標を渡すと自分で作業し続ける Goal Mode が標準になり、Windows でのコンピュータ操作やスマホからの遠隔操作にも対応しました。実際のテストでは、Pydantic というライブラリの大規模移行(1.4万行)を約31時間・44ドルでこなした、という報告まであります。

| 項目 | 内容 |
|---|---|
| フラッグシップ | GPT-5.5("Spud")、GPT-5.5 Instant が ChatGPT の既定モデル |
| 主要スコア | 汎用知能 Index 60、Terminal-Bench 2.0 で 82.7% |
| 注目機能 | Codex Goal Mode 標準化 + Computer Use(Windows)+ 遠隔操作、Rosalind Biodefense(政府向け公開) |

**強み**: とにかく守備範囲が広いんです。チャットも文章も画像もコーディングも、ひとつのサブスクで一通りこなせて、企業向けのセキュリティや調達経路の選択肢も豊富。開発者向けのAPIやSDKの充実度でも、いまのところ一番手厚いと感じます。

**弱み**: ただ、整理のしかたで足元を少しすくわれています。文章作成に使えた Canvas という機能を予告なく消してしまい、「黙って消すのはひどい」という批判がこの期間でいちばん大きな声になりました。GPT-4.5 が6月27日、o3 が8月26日に ChatGPT から引退する予定なのも、愛用していた人には寂しいニュースですね(APIには影響しません)。

### Google AI ─ 表現の幅と安さ、そして「常駐する相棒」

Google AI は5月19日の開発者イベント I/O 2026 が最大の山でした。新モデル **Gemini 3.5 Flash** を正式公開し、なんと「廉価版なのに前世代の上位モデル(3.1 Pro)を多くの指標で上回る」という驚きを見せたんです。さらに、動画から作り始めるマルチモーダル生成の Omni、24時間あなたの代わりに動く常駐エージェントの Spark、研究者向けの Gemini for Science まで、一気に並べてきました。重心がいよいよ「チャット」から「自律的に動くエージェント」へ移ってきたな、という印象です。

| 項目 | 内容 |
|---|---|
| フラッグシップ | Gemini 3.5 Flash(2026-05-19 GA、入力 $1.50 / 出力 $9.00)。上位の 3.5 Pro は2026年6月予定 |
| 主要スコア | Terminal-Bench 2.1 で 76.2%、前世代 3.1 Pro を多指標で上回る |
| 注目機能 | Omni(動画生成統合)、Spark(24/7 常駐エージェント)、Gemini for Science |

**強み**: 画像・動画・音声まで含めた表現力の幅と、コストの安さは依然として武器です。リサーチ用途やマルチモーダルの理解では、やっぱり Google が強いという評価が根強く残っています。日本語まわりの情報発信が活発なのも、日本のユーザーにはありがたいところですね。

**弱み**: ただ今回は逆風も多めでした。3.5 Flash の料金が旧 Flash の3倍に上がったことへの「値上げか」という声、無料で使えた Gemini CLI が6月18日で終了して強制的に移行させられること、さらに常駐エージェント Spark がメールや決済にアクセスする以上プライバシーは大丈夫なのか、という不安。便利さと引き換えの摩擦が、あちこちで顔を出した3週間でした。

## コーディングツール2強のポートレート

ここからは、基盤モデルを「道具として積んで」開発者の手元で動かす2社の話です。Cursor も GitHub Copilot も中身では Claude や GPT、Gemini を選んで使えるんですが、プロダクトとしての体験はけっこう違うんですよね。

### Cursor ─ 自社モデルの「コスパ」で攻める

Cursor は5月18日に自社モデル **Composer 2.5** を更新しました。第三者の評価で「ライバルの10〜60分の1のコスト」とまで言われていて、1タスクあたりだいたい7セント前後で動くという安さが武器です。クラウド上でエージェントの開発環境をまるごと用意できる仕組み(Dockerfile やマルチリポジトリ対応、キャッシュで7割高速化)も整え、「ちょっと試す」から「本番でエージェントの群れを運用する」段階へ踏み込んできました。Microsoft Teams や Jira から `@Cursor` と呼べば動き出す連携も増えて、エンジニア以外の人も巻き込もうとしています。

| 項目 | 内容 |
|---|---|
| 代表機能 | Composer 2.5(自社モデル)、Tab 補完、Auto-review Run Mode、Cloud Agent 開発環境 |
| 採用モデル | 自社 Composer 2.5(Moonshot Kimi K2.5 ベース)を既定に、Claude / GPT-5.5 / Gemini 3.5 Flash なども選択可 |
| 主要プラン | Pro $20 / Pro+ $60 / Ultra $200 |

**強み**: なんといってもコスパです。「3時間かかっていた作業が15分で終わった」「月60ドルで十分なトークンが使える」といった実感の声が日本語圏でもよく見られます。日々の補完からエージェント運用まで、速さと安さのバランスがいいんですよね。

**弱み**: ただ「ベンチマークは良いけど日常の体感は別物」という冷静な見方もあって、長時間タスクをこなすには上位プランがほぼ必須、トークン消費の読みづらさも残っています。過信せず、ちゃんと監督する姿勢が大事、という慎重論はおさえておきたいところです。

### GitHub Copilot ─ プラットフォーム統合の「標準ツール」

GitHub Copilot の目玉は、5月14日に技術プレビューとして出た独立アプリ **GitHub Copilot app** です。これまで IDE 拡張・CLI・Web にバラバラだった Copilot を、「エージェントを束ねて指揮する専用クライアント」として初めて一本化したものなんです。セッションごとに作業ツリーを分けて並列で走らせたり、CI を直しながらマージまで自律でやってくれたり(Agent Merge)と、同社が掲げる "Agent HQ" 構想の最初の具体物になっています。

| 項目 | 内容 |
|---|---|
| 代表機能 | GitHub Copilot app(Focused Sessions / Agent Merge)、Code Review、補完(AI Credits 不消費) |
| 採用モデル | Claude(Opus 4.8 まで)/ OpenAI(GPT-5.5 系)/ Google(Gemini 3.5 Flash)など幅広く選択可 |
| 主要プラン | Free / Pro $10 / Pro+ / Business / Enterprise + 新 Max($100) |

**強み**: GitHub というプラットフォームに深く食い込んでいる強さは別格です。Issue・PR・Runner と地続きで使えて、IDEの対応範囲も広く(Eclipse 版は MIT でオープンソース化されました)、FedRAMP や組織ごとのモデル制御など、企業の調達担当が求める条件をきっちり押さえています。日々の補完が課金を消費せず無制限なのも、安心して使える土台です。

**弱み**: いちばんの逆風は課金です。6月1日からの従量課金への移行(繰り越しなし・年額廃止)に「実質値上げでは」「メーターを見るたびにヒヤッとする」という声が量・強さともに最大になりました。新規のサインアップが約41日も止まっていた点も含め、コスト面での不安が当面ついて回りそうです。

### もう一歩踏み込んだ判断ガイド

**スタートアップや中小企業で、自律コーディングの土台を整えたいなら。** Claude Code(Auto モードが Pro でも使えるように)と Cursor(Composer 2.5 の安さ)を併用するのが現実的だと感じます。大きなタスクは Claude に背景で並列処理させ、こまめな反復は Cursor でコスト効率よく回す、という分担ですね。GitHub Copilot を使う場合は、6月1日の課金移行前に一度コストを試算しておくのがおすすめです。

**金融・医療・公的機関のような規制の厳しい現場なら。** データを社外に出さずにエージェントを動かせる Claude Enterprise が、ひとつの軸になります。そこに FedRAMP 対応やモデル制御がそろった GitHub Copilot Enterprise を組み合わせると、調達要件をかなり満たせるはずです。新しい常駐エージェント系の機能は、専用のプライバシーポリシーが整っているか確認してから入れたほうが安心です。

**大量の資料を読み解くリサーチや、画像・動画を扱う業務が中心なら。** ここは Google AI が一歩リードしています。長い文脈を扱う力、研究者向けの Gemini for Science、そして動画生成まで含めた幅は、ほかにない強みです。音声を本番で使いたい場合は OpenAI の Realtime も選択肢になりますね。

## 直近で本当に重要だった動き

この3週間でいろいろありましたが、「これは覚えておいたほうがいい」というものを4つに絞ってお伝えします。情報量で勝負せず、本当に効いてくるものだけを。

### 「賢いモデル1個」より「エージェント1,000個」が話題をさらった

Claude の Opus 4.8 と同時に出た Dynamic workflows は、最大1,000個のサブエージェントを背景で並列に走らせ、中間結果をスクリプトの変数に持たせて文脈の飽和を避ける、という仕組みです。複数の技術メディアが「これは本体のモデルより構造的に重要かもしれない」と評したほどで、評価の物差しが「モデルがどれだけ賢いか」から「エージェントをどれだけ正しく並列に走らせられるか」へ動いた瞬間だったと見ています。ただ「47個起動して成功は25個、人間のレビューに5時間」という生々しい報告もあって、まだ発展途上なのも確かなんですよね。

### 廉価版モデルが上位モデルを追い抜いた

Google の Gemini 3.5 Flash が、廉価帯でありながら前世代の上位モデルを多くの指標で上回ったことは、地味だけど大きな出来事でした。おかげで「対話型コーディング」の用途では、主要5サービスのうち4つが実用水準(○以上)に並ぶ底上げが起きています。安いモデルでもここまでやれる、となると、選ぶ側の発想もずいぶん変わってきますよね。

### エージェントが「席を離れても働く」段階に入った

OpenAI の Codex が目標を渡すと数十時間自走するようになり、GitHub Copilot は並列セッションをまとめて指揮する専用アプリを出し、Cursor は許可リストとサンドボックスで半自律のレビューを走らせる機能を加えました。4つのサービスが横並びで「人間が介在する回数を減らす」方向に動いたんです。コーディングの主役が「人が書く」から「エージェントの群れを束ねる」へ移りつつあると感じます。承認を減らすぶん、安全とのバランスをどう取るかが次の課題ですね。

### 課金と旧機能の整理が、あちこちで摩擦を生んだ

GitHub Copilot の従量課金移行、OpenAI の Canvas 廃止、Google の Gemini CLI 終了。便利さを追って製品を素早く作り変える各社の姿勢と、「予測できる安定した運用」を求める利用者との間で、緊張が生まれた3週間でもありました。新機能のニュースの裏で、こうした「足元の使い勝手」への声もちゃんと拾っておきたいところです。

## これから何が起きるか ─ わたしの見立て

ここからは少し先を想像してみます。まず、「規模の階層」をめぐる競争が本格化するんじゃないかと見ています。Claude が最大1,000個のサブエージェント、OpenAI が数十時間の自走、Google が並列マルチエージェントと常駐エージェント、とみんな同じ方向を向いていますから、2026年後半は「モデルの賢さ」より「エージェントをどれだけ正しく並列に走らせられるか」が競争の中心になりそうです。

コストの見方も変わってくると思います。名目の安さより「実際にいくら消費したか」「読みやすいか」が評価軸になってきていて、6月1日に GitHub Copilot の従量課金が実際に始まると、コーディングツールのコスパ評価はしばらく流動的になると見ています。

6月は Google にとって山場になりそうです。上位モデルの Gemini 3.5 Pro が登場予定で、これが出れば技術力の評価が上振れする余地があります。ただ同じ6月に Gemini CLI の強制移行も控えていて、移行の摩擦が使い勝手の評価を引っ張る可能性も否めません。
