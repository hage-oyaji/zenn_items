# 2026年6〜8月 AIハーネス インプレッションTOP10
## 直近3ヶ月だけで測り直したら、順位が9つ動いた

> **調査基準日：2026年9月3日**
> 対象期間：**2026年6月3日〜9月3日(直近3ヶ月)**
> 並べ替えの基準：Hacker News 上のインプレッション量
> 比較対象：同じ手法で測った直近12ヶ月版

前回、直近12ヶ月で同じ集計をした。

結果はこうだった。

```text
1位 Claude Code   94,204
2位 Codex         21,301
3位 OpenClaw      19,964
   ...

```

**製品が上位を独占し、ハーネスという概念そのものは14位だった。**

ただ、12ヶ月は長い。

2025年9月と2026年8月では、そもそも議論の前提が違う。

だから、**直近3ヶ月だけで測り直した。**

そして、順位が大きく動いた。

---

## 測り方(12ヶ月版と同一条件)

```text
インプレッション = Σ(ポイント) + Σ(コメント数)

対象 : Hacker News のストーリー
期間 : 2026-06-03 〜 2026-09-03(3ヶ月)
条件 : 100pt 以上(= フロントページ到達)
検索 : 12ヶ月版と同じ164語をフレーズ検索し、
       同じ22トピック定義で束ねて重複排除
```

閾値・検索語・トピック定義をすべて揃えてある。

**変えたのは期間だけ**なので、順位の変動はそのまま「この3ヶ月で何が語られたか」の変化を表す。

50pt まで閾値を下げた版でも検算したが、上位10の顔ぶれは変わらなかった(7位と8位が入れ替わるだけ)。

### ただし、1つ補正した

12ヶ月版で「ローカル推論ハーネス」を **Ollama / llama.cpp / vLLM / SGLang** という**製品名だけ**で検索していた。

これが誤りだった。

この3ヶ月に起きていたのは、製品の話ではなく**「ローカルで動かす」という選択そのもの**の話だったからだ。

```text
Running local models is good now                              (1,596pt)
Ask HN: Claude/GPT をローカルモデルに置き換えた人はいるか      (1,318pt)
Gemma 4 26B を 2GB RAM で動かすOSSエンジン                    (  919pt)
Small Models Have Arrived                                     (  799pt)
```

これらは製品名で引っかからない。

そこで `local model` / `local models` / `small models` / `on-device` を検索語に追加した。

**補正の影響は大きい。**

| | 12ヶ月 | 3ヶ月 |
|---|---:|---:|
| 製品名だけ(12ヶ月版の定義) | 7,218(10位) | 1,543(8位) |
| **検索語を補正** | **16,956(4位相当)** | **9,574(2位)** |

12ヶ月版の10位という数字は過小評価だった。ここで訂正する。

以下、TOP10は補正版で示し、順位変動の分析は**補正なしの同一定義**で行う(そうしないと比較にならないため)。

## この3ヶ月で読み取れる4つのこと

### 1. Claude Code は「首位のまま失速」した

集中度 **13.6%**。基準線25%の半分ほどしかない。

月次を見ると明確だ。

```text
2026-04  19,543  ← ピーク(ソース流出・品質劣化・課金変更が重なった月)
2026-05   6,639
2026-06   5,434
2026-07   4,370
2026-08   2,974  ← ピークの 15%
```

**4ヶ月で6分の1以下になった。**

ただし、これを「人気の低下」と読むのは早い。

12ヶ月版で見た通り、Claude Code のインプレッションは**事件で稼いでいた**。ソース流出、品質劣化、第三者ブロック、ステガノグラフィ疑惑。

事件が減れば数字は落ちる。

直近3ヶ月の19本を見ると、性質が変わっている。

```text
6〜8月に残った話題
  トークン過剰(33k問題)
  Bun/Rust への移行
  Auto モードが既定に
  Extended Thinking の表示テキスト
  Alibaba が社内利用を禁止
  週次上限のプロモーション
```

**炎上から、運用と実装の話に移った。**

これは成熟の兆候でもある。

### 2. Codex が Claude Code に肉薄した

12ヶ月では 4.42倍の差があった。

```text
12ヶ月  Claude Code 94,204 : Codex 21,301  →  4.42倍
 3ヶ月  Claude Code 12,778 : Codex  8,841  →  1.45倍
```

**差が3分の1に縮まった。**

Codex の集中度は 41.5%。基準線を大きく超えている。

7月には Codex(3,814)が Claude Code(4,370)にほぼ並び、8月も 2,322 対 2,974 と僅差だ。

「A week of using Codex more than Claude」(2026-08-21 / 248pt / 281コメント)のような記事が出てくる状況になった。

## 「削る」が主流になった

7月25日の記事(463pt / 404コメント)が、この3ヶ月で最も影響が大きかった。

Claude Code の system prompt を **80%以上削除しても、コーディング評価に測定可能な劣化はなかった**、という報告である。

```text
Then                          Now
────────────────────────────────────────────────
明示的なルールを与える      → 判断を委ねる
ツールの使用例を書く        → ツールのインタフェースを良くする
情報を前倒しで全部入れる    → Progressive Disclosure
指示を繰り返す              → ツール説明はシンプルに
CLAUDE.md に手動で記憶      → 自動保存
```

出典: [The new rules of context engineering for Claude 5 generation models](https://claude.com/blog/the-new-rules-of-context-engineering-for-claude-5-generation-models)

そして8月13日の「How Compaction Works in Pi」(211pt)は、**畳み方の実装**を公開している。

「積む」の議論が終わり、「削る」「畳む」「外に置く」の実装が始まった3ヶ月だった。

# 調査方法

### 12ヶ月版との差分

```text
同じもの : API(HN Algolia)/ 閾値(100pt)/ 検索語164語 /
           トピック定義22個 / 重複排除の方法 / ノイズ除去規則
違うもの : 期間のみ(2026-06-03 〜 2026-09-03)
```

### 追加でやったこと

| 内容 | 目的 |
|---|---|
| 閾値50ptでの再計算 | 上位10の順序が閾値依存でないことの確認(7位と8位が入れ替わるのみ) |
| 検索語16語の追加収集 | ローカル実行・サンドボックス・経済性の取りこぼし確認 |
| 月次集計(2025-09〜2026-08) | 順位変動が「いつ」起きたかの特定 |
| 250pt以上の全記事スキャン | トピック定義から漏れた主題の発見(ハーネスの経済性はこれで見つけた) |

### この調査の限界

1. **3ヶ月は短い。** 1本の大型記事(1,000pt級)が順位を動かす。Cursor の8月1位はその例である
2. **記事数が少ない。** 7位以下は3〜5本で構成されており、統計的な安定性は低い
3. **検索語のバイアス。** ローカル実行とセキュリティで実際に取りこぼしが見つかった。他にもある可能性が高い
4. **話題量は重要度ではない。** Codex ハーネスの Apache-2.0 公開が **2pt**、「ハーネスとは何か」の記事が **587pt** という事実が、その最も明確な例である

# 最後に

12ヶ月で測ったとき、1位は Claude Code で、ハーネスという概念は14位だった。

3ヶ月で測り直したら、Claude Code はまだ1位だが**ピークの15%まで落ち**、ハーネス概念は**5位まで上がっていた**。

そして、この3ヶ月に起きたことは、ほぼ一つの流れで説明できる。

```text
Uber が示した「報酬の11%」というコスト
        ↓
小さいモデルが実用水準に到達(1リクエスト $1 → $0.10)
        ↓
モデルがコモディティになる
        ↓
差がつく場所がハーネスに移る
        ↓
「ハーネスとは何か」が8月に5本
```

12ヶ月版の最後に、私はこう書いた。

> 話題の総量は製品に集まる。しかし性能を決めているのは、順位が低いほうの層である。

3ヶ月版では、少し変わった。

**順位が低かった層が、上がってきている。**

ただし、忘れてはいけないことが一つある。

実物のハーネスが Apache-2.0 で公開された記事は、**2pt** だった。

語られる量と、使われる量は違う。
