## いま、AIの勢力図はこうなっている

総合点で並べれば OpenAI(25/30)・Claude(20/30)・Google AI(15/30)という基盤モデル3社の序列に大きな変化はありません。しかし表面のスコアより興味深いのは、**3社の戦略線が同時にズレ始めた**ことです。OpenAI は GPT-5.5 Instant を ChatGPT のデフォルトに据えながら Realtime 2 で音声 AI を本番市場へ押し出し、Codex for Chrome 拡張で SaaS 業務に常駐し、Excel/Sheets を全プランで GA 化しました。Anthropic は新モデルを投入する代わりに SpaceX Colossus 1(300MW・220K GPU)で物理 compute を太らせ、Multiagent / Outcomes / Dreaming / Webhooks の 4 機能を同日公開して「永続自走エージェント」体系を完成させ、24 時間以内に Wall Street + 中堅企業の業界別パッケージ化を始めました。Google は Gemini 3.1 Flash-Lite を GA 化しつつ Box / 15 種の新規データストアを Knowledge Catalog に積み増し、Workspace を毎週小刻みに磨いて I/O 2026(2026-05-19〜20)の地ならしに入っています。コーディングツール側では、Cursor が 3.3 で PR ライフサイクル全体を IDE に取り込み、GitHub Copilot は VS Code April releases v1.116-v1.119 でブラウザとターミナルとセッションをエージェントに開放しました。

この俯瞰を支える論点を3つだけ抽出すると:

- **業務常駐の同時多発化** ── ChatGPT for Excel / Sheets GA、Codex for Chrome、Cursor 3.3 の PR Review、Copilot の Integrated Browser、Gemini for Home の全 early access ロールアウトが 9 日間に集中。
- **業界別パッケージ化のはじまり** ── Anthropic for Financial Services と Enterprise AI services 合弁が 24 時間以内に 2 公開され、基盤モデル提供者が「業種別バンドル」へ動き出す。
- **永続自走エージェントの実用化** ── Memory に Multiagent + Outcomes + Dreaming + Webhooks + Vault が加わって 6 機能体系が成立し、Harvey が「6x 完了率」、Spiral が「Haiku 司令 + Opus 起草」という具体例を出した。

## 使い分けの判断軸

モデルの絶対性能で選ぶ時代から、**用途と業務プロセスへの適合度で選ぶ時代**へ移っています。同じ「コード支援」でも対話型 IDE と PR レビュー自動化では推奨が変わり、エンタープライズ導入では規制要件と業界バンドルの組み合わせが重要です。次の早見表は、いま自分が立っている用途を起点にして「どこから検討するか」の取っ掛かりにしてください。

### もう一歩踏み込んだ判断ガイド

**スタートアップで自律コーディング基盤を選ぶなら**

Claude Code(Pro $20)と Cursor(Pro $20)の併用が現実的です。Claude Code は Multiagent + Outcomes + Dreaming + Webhooks で複雑タスクを永続的に走らせ、Cursor は Cursor 3.3 の PR Review と Build in Parallel で「書く速度」を加速します。SpaceX 提携で Claude Code の 5 時間 usage 上限が 2 倍化し peak-hour reduction も撤廃されたので、「3-4 query で weekly limit に当たる」という長年の主訴が緩和されました。GitHub Copilot Pro $10 を IDE 補完の常用に置きながら、OpenAI Codex を Codex for Chrome から SaaS 操作に使うという布陣もコストパフォーマンスは高いはずです。

**規制業界(金融 / 医療 / 公的機関)のエンタープライズ導入なら**

Anthropic for Financial Services(Opus 4.7 駆動、10 templates、Microsoft 365 統合、Moody's MCP)と GitHub Copilot Enterprise(FedRAMP + LTS + IP インデムニティ + Cloud agent secrets 組織レベル化)の併用を最初に検討する価値があります。Claude が「Wall Street + 中堅企業の業界別パッケージ化」へ動いたことで、用途別マトリクスでも「企業向け・エンタープライズ」が ◎ 評価へ届きました。OpenAI Enterprise も SSO/SAML + Compliance API + EKM + ChatGPT for Intune + GPT-5.5-Cyber + AAS + 3 経路調達で守備範囲が広く、Google AI の Gemini Enterprise は Box GA + Knowledge Catalog 拡張で「公式データソースの幅」が伸びました。ただし Mythos 政府反対と Memphis Colossus 環境問題、Google の課金システム不具合、Gemini Enterprise の UI 過密 / 価格 / 旧システム接続性は導入前に必ず確認したい項目です。

**大規模リサーチ / マルチモーダル業務担当なら**

Google AI が依然として第一選択です。Gemini 3.1 Pro と NotebookLM、Notebooks in Gemini、Deep Research Agent API、2026-05-08 GA の Box data store と 15+ 新規データストアの組み合わせは、業務範囲を SaaS / 学術 / クリエイティブ / クリプトまで一気に広げます。Flash-Lite GA で「料金最安帯モデルが正式 GA で安心感」があり、Free Tier + Batch + Context Caching の 3 段組合せが正式に使える状態になりました。OpenAI Pro $200 の Deep Research + Atlas Browser Memories + Memory sources + GPT-5.5 Pro と、Claude Pro / Max の Research + 1M context + Dreaming による永続的調査ワークフローを補助に置くと、3 社をうまく使い分けられます。

**中小企業の事務作業効率化なら**

ChatGPT for Excel and Google Sheets GA(2026-05-05、全プラン、Free / Go / Plus / Pro / Business / Enterprise / Edu / K-12)が日本語実務メディアの注目を集めています。AI WAVE / わかるネット / チャエンの AI 研究所 / AI フレンズ / sbbit などが「導入手順 + 業務プロンプト」を多数掲載し、Excel の数式修正やデータクリーンアップが自然言語で動く体験は中小企業の事務作業効率化に直結します。Google AI の Set custom instructions for Gemini in Docs + Help me write in Gmail 改良 + Workspace Studio 7 言語追加 + Notebooks in Gemini を併用するのも自然な組み合わせです。Business 以上は 2026-06-02 まで free preview で、その後 credits 課金になる点だけは事前に試算しておきたいところです。

## これから何が起きるか ─ 筆者の見立て

業界別パッケージ化のドミノは 5 月後半から 6 月にかけて加速していくと見ています。Anthropic は Healthcare / Legal / Manufacturing / Retail と業界別バンドルを量産し、OpenAI は ChatGPT for Intune や Composer for Enterprise の延長で「Microsoft Endpoint 環境の AI」を一段深め、Google AI は I/O 2026(2026-05-19〜20)で Gemini 3.2 Flash と AlphaEvolve Cloud rollout、Project Jitro(Jules V2)の発表をまとめて投入する可能性が高いと推測されます。

永続自走エージェントの収益モデルも興味深い局面に入ります。Anthropic は Memory + Multiagent + Outcomes + Dreaming + Webhooks + Vault の 6 機能体系を当面は安価な session-hour 課金で普及させ、後期(2026 Q3 以降)には memory store 数や dreaming スケジュール、multiagent thread 数で従量課金を追加していく 2 段戦略を採るのではないかと見ています。OpenAI は Workspace Agents が credits 課金へ移行し、ChatGPT for Excel-Sheets も 6/2 以降 credits 課金になることで、「ChatGPT サブ + API token + 業務統合 credits」が ARR の第 3 の柱に育つ過程に入りました。

コーディングツール 2 強の差別化はさらに鮮明になりそうです。Cursor は「PR ライフサイクル統合 + Security Review + Composer 自社モデル」、GitHub Copilot は「VS Code エージェント実装基盤 + GitHub プラットフォーム統合 + BYOK 6 接続先」と、選好軸が交差せずに棲み分けていく方向に進んでいます。Cursor → Claude Code / VSCode 離反派の発信が日本語圏で続いていることも考えると、コーディングツール選定は「単一サービスを選ぶ」から「複数サービスと基盤モデルの組み合わせを選ぶ」へ変質していくと見ています。

最後に、ESG / 規制リスクの行方も注視に値します。Anthropic Mythos の White House 拡大反対は本日 2026-05-10 まで公式 reply がなく、Memphis Colossus の Clean Air Act 違反報道(2026-05-07 Fortune)とあわせて二重 ESG リスクとして残っています。$50B 調達ラウンドの最終評価額がこれらリスクをどの程度織り込むか、同社の規制対話力の試金石として継続観察事項です。OpenAI が AAS + Trusted Contact + GPT-5.5-Cyber + TAC 三層化で逆方向の「責任ある AI プラットフォーム」ブランドを構築しているのと対比的で、規制環境の中で「誰が安心感を売れるか」が次のブランド競争の軸になる可能性があります。
