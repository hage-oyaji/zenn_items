## いま、AIの勢力図はこうなっている

まず全体像です。土台になるモデルを作っているのが Claude / OpenAI / Google AI の3社、その土台を使って開発者向けの道具に仕立てているのが Cursor と GitHub Copilot の2社、という二層構造で見てください。この6月、基盤モデル3社では OpenAI が総合23点(30点満点)で首位、Claude が22点、Google AI が15点という並びになっています。首位と2位の差はたった1点で、かなり競っている状態なんです。その競り合いを生んだのが、Claude の Fable 5(6/9公開)という看板モデルでした。Anthropic はこれを「一般提供された中でいちばん高性能」とうたって世に出し、モデルの実力を測る評価で先頭に立ちました。一方で OpenAI の次世代 GPT-5.6 は信頼できるパートナー限定のお試し公開にとどまり、Google の看板モデル Gemini 3.5 Pro は7月へ延期。「作れた」だけでなく「出せた」Claude が、点差を詰める原動力になっています。

この俯瞰を支える論点を3つだけ挙げると、こうなります。

- **フロンティアは「出せたか」で明暗** — Claude は Fable 5 を全世界公開できた一方、GPT-5.6 は限定お試し、Gemini 3.5 Pro は延期。
- **安いのに高性能なモデルが受け皿に** — Claude の Sonnet 5 が Opus 4.8 級の性能を入力 $2 / 出力 $10(100万トークンあたり)の導入価格で出し、コスパ評価を押し上げました。
- **コーディングツールは課金の摩擦が主役** — GitHub Copilot の使った分だけ課金への移行が「請求ショック」として噴き出し、総合はCopilot 14点・Cursor 10点で競り合っています。

## 基盤モデル3社のポートレート

土台を作る3社は、それぞれ向いている方向がかなり違います。同じ「AIの基盤モデル」でも、Claude は開発と自動化、OpenAI は何でも屋、Google AI はモダリティの幅、という具合にキャラが立っています。順番に見ていきましょう。

### Claude ─ 三段構えのモデルで天井と入口を同時に塗り替えた月

Anthropic の6月は、看板の刷新と入口の刷新を同時にやってのけた点が印象的でした。まず最上位に Fable 5(`claude-fable-5`、入力 $10 / 出力 $50)を据え、「ほぼすべての公開評価で最先端」と主張。同じ月末には普及帯の Sonnet 5(`claude-sonnet-5`、導入 $2/$10 → 標準 $3/$15)を出し、無料プランと Pro プランの標準モデルにしました。これで、いちばん重い仕事は Fable 5、日常づかいは Sonnet 5、その中間を Opus 4.8($5/$25)が担う三段構えができたわけです。さらに Slack から `@Claude` に仕事を頼める Claude Tag や、作業の成果を共有ページにまとめる Artifacts も投入し、「コードを書く道具」からチームで使うプラットフォームへ広げようとしています。

**主力モデル・価格**

| 項目 | 内容 |
|---|---|
| 看板モデル | Fable 5(入力 $10 / 出力 $50、6/9公開、最上位) |
| 普及モデル | Sonnet 5(導入 $2/$10 → 標準 $3/$15、Free/Pro 既定、Opus 4.8級) |
| 注目機能 | Claude Tag(Slack委任)、Artifacts(共有ページ)、Claude Science(科学者向けベータ) |

**強み**: モデルの実力を測る評価で先頭に立ち、大規模な移動や監査を最後までやり切る力に定評があります。約40回にわたる Claude Code のこまめな更新や、親AIが子分のAIを何段にも呼び出して分担させる仕組みも、開発現場での厚い支持につながっているんです。

**弱み**: Fable 5 が輸出管理を理由にいったん止まり(6/12)、月末に再公開(6/30)された経緯があり、提供が続くかに地政学リスクが乗りました。Opus 4.8 で道具呼び出しが壊れる不具合が日本語の長いやり取りで出やすいと報告されている点も気がかりです。

### OpenAI ─ 何でも屋の強さは健在、次世代の一般開放が宿題

OpenAI は、一つの契約であらゆる用途をカバーする「何でも屋」の立ち位置を保っています。消費者向けの ChatGPT では標準モデルの GPT-5.5 Instant を6/24に改善し、古い GPT-4.5(6/26)や GPT-5.2(6/12)を引退させて最新世代へ一本化しました。同じ6/26には次世代の GPT-5.6 Sol/Terra/Luna を出したものの、これは信頼できるパートナー限定のお試し公開で、いつ誰でも使えるようになるかは未定です。開発まわりでは、席を離れても自走してくれる Codex を全プランで正式公開(6/25)し、画面を操作させる機能をヨーロッパへ広げるなど、自動化の裾野を一気に広げています。

**主力モデル・価格**

| 項目 | 内容 |
|---|---|
| 消費者向け | GPT-5.5 Instant(ChatGPT 既定、6/24改善)、GPT-5.5 Pro |
| 次世代 | GPT-5.6 Sol/Terra/Luna(6/26、限定お試し、一度に読める量が本数冊分の1.5M) |
| 注目機能 | Codex 正式公開(自走コーディング)、Scheduled Tasks(予約実行) |

**強み**: 開発者向けの窓口づくりや、統合できる外部サービスの幅で先行しています。第三者の評価サイト G2 でも星4.7(2,000件超)と高く、大手英語メディアが動きを集中的に取り上げるので、話題の中心にいられる強さがあります。

**弱み**: 事実でないことをもっともらしく答えてしまう頻度への批判が英語圏で目立ってきました。古いモデルの引退を立て続けに実行したことで「前の出力に戻れない」という不安も出ています。GPT-5.6 をいつ一般開放するかがはっきりしないのも、様子見の材料になっています。

### Google AI ─ 看板は延期、周辺の幅と企業向け基盤で押す

Google AI は、モダリティ(文章・画像・音声・動画をまとめて扱う幅)の広さで勝負するフルスタック型です。ただ6月は、看板の Gemini 3.5 Pro が公開ページすら出ないまま7月へ延期となり、主役不在のまま進みました。その代わり、動画を作れる Gemini Omni Flash や音声のリアルタイム翻訳 Live Translate、超低コストの画像モデル Nano Banana Lite など、周辺の道具を薄く広く出しています。日常帯の Gemini 3.5 Flash(入力 $1.50 / 出力 $9.00)は速くて安いと日本語圏でも評判で、日本語性能では3社の中で先頭に立っています。そして今月の実質的な主役は、企業がAIエージェントを本番運用するための Gemini Enterprise 関連機能を一気に正式公開したことでした。

**主力モデル・価格**

| 項目 | 内容 |
|---|---|
| 日常帯 | Gemini 3.5 Flash(入力 $1.50 / 出力 $9.00) |
| 看板 | Gemini 3.5 Pro(2026-07-01時点で未提供、7月へ延期) |
| 注目機能 | Omni Flash(動画生成)、Live Translate(音声)、Nano Banana Lite(低コスト画像) |

**強み**: 音声・動画・画像をまとめて扱う力が頭ひとつ抜けていて、長い文章をまるごと読ませる用途では Gemini 3.1 Pro が頼れます。企業のエージェント運用を支える機能をそろえた点も、大きな前進です。

**弱み**: 開発者向けの Gemini CLI を6/18に終了させ、無料枠を約98%も減らしたことが「おとり商法だ」と炎上しました。使える回数がすぐ尽きるという不満も英語圏・日本語圏の双方で相互に裏づけられていて、看板の延期と合わせて逆風になっています。

## コーディングツール2強のポートレート

ここからは、基盤モデルを取り込んで開発者向けの道具に仕立てる Cursor と GitHub Copilot です。同じモデルを使っても、道具としての体験はまるで違います。この2社の総合はCopilot 14点・Cursor 10点(16点満点)で、Copilot が構造的に広い一方、開発体験とコミュニティの温度感では競り合っている、という構図です。

### Cursor ─ 自社モデルの安さと補完体験で「書く速度」を推す

Cursor の持ち味は、自社モデル Composer 2.5 の安さ(1タスクおよそ $0.07)と、入力を先読みして補完してくれる Tab の気持ちよさです。6月はモデル世代の更新をあえて見送り、運用基盤とプラットフォームの拡張に振り切りました。10分で開発環境を用意する Cloud Environment Setup、企業向けに組織・チーム・グループの3階層をそろえた Organizations の正式公開、そして iOS 版アプリ(6/29)まで出しています。Anthropic の新世代(Fable 5 / Sonnet 5 など)もすぐ選べるようにしていて、モデルを選ぶ自由度も高いんです。

**主要機能・プラン**

| 項目 | 内容 |
|---|---|
| 代表機能 | Tab 補完、Composer 2.5(自社モデル)、Bugbot(不具合レビュー) |
| 採用モデル | Composer 2.5 を既定に、Anthropic 新世代 / Gemini / GPT 系を選択可 |
| 主要プラン | Pro $20、企業向け Organizations(3階層) |

**強み**: 製品としての評価が高く、Product Hunt では星5.0(893件)を集めています。安く速く反復できるコスパの良さが、コーディングツールの中では光ります。

**弱み**: 頼みの Composer 2.5 が6月に「遅い・落ちる」という苦情をフォーラムで集めてしまいました。安いはずが実際には待たされる、という体験のブレが評価の重しになっています。

### GitHub Copilot ─ 幅は最強、でも「請求ショック」が最大の逆風

GitHub Copilot は、GitHub というプラットフォームに深く食い込んだ標準ツールとして、企業が求める要件をひととおり満たしています。6月はお試し版から正式版への一斉昇格が起き、単体アプリの正式公開(6/17、目玉は人とAIが同じ画面で作業する Canvases)や、外部から機能を組み込むための窓口 SDK の正式公開などが並びました。ところが同じ6月、いちばん話題になったのは機能ではなく課金です。6/1に「使った分だけ払う」方式へ移行したところ、公式アナウンスに反対958・賛成24という激しい反発が集まり、「月$29が$750になった」といった実測ベースの悲鳴が噴き出しました。

**主要機能・プラン**

| 項目 | 内容 |
|---|---|
| 代表機能 | 単体アプリ(Canvases)、SDK、コード補完 |
| 採用モデル | Claude(Sonnet 5 正式提供)、GPT 系、Gemini 系、自社系の MAI-Code-1-Flash |
| 主要プラン | Pro $10、Business / Enterprise(組織横断の予算管理あり) |

**強み**: あらゆるIDEに対応する幅と、政府向けの高いセキュリティ基準まで満たす統制力があります。何より、コード補完が使った分だけ課金の対象外で無制限のまま残った点が、いちばんの安心材料になっています。

**弱み**: 課金移行の「請求ショック」が実測ベースで最大化してしまいました。枯渇時に別モデルへ逃がす仕組みをやめたため、限度に達すると全社で止まりうるという不安も残っています。

### もう一歩踏み込んだ判断ガイド

**スタートアップで自律コーディングの土台を選ぶなら**

Claude Code(Sonnet 5 を標準に、重い時だけ Opus 系)と Cursor(Composer 2.5 の安い反復)を組み合わせるのがおすすめです。ただ Cursor は6月の Composer 2.5 の不調が残っているので、動きが重いと感じたら別モデルへ切り替えてみてください。

**金融・医療など規制の厳しい業界で導入するなら**

データを自社の管理下に置ける Claude Enterprise と、政府向け基準を満たす GitHub Copilot Enterprise の併用が手堅い選択です。Fable 5 の提供が止まりうる点や、Copilot が限度到達で全社停止しうる点は、導入前に必ず確認しておきましょう。

**大量のリサーチやマルチモーダル業務なら**

長い資料を読ませる力とモダリティの幅で Google AI が向いています。使える回数がすぐ尽きる問題と、看板 Gemini 3.5 Pro が7月へ持ち越された点は頭に入れておいてください。補助には OpenAI の Deep Research や Claude の科学者向けベータも使えます。

**音声・動画や画像を本番で使うなら**

動画は Google AI がほぼ一択で、音声も Live Translate が強力です。ただ Omni は3〜10秒・720pの制約があり、日本語音声はまだ発展途上。OpenAI は音声なら選べますが、動画づくりからは実質手を引いています。

## 今月の注目トピック

6月に本当に動いたのは、次の3つだと見ています。網羅よりも、覚えておく価値のあるものに絞りました。

### 「一般提供できたか」がフロンティアの明暗を分けた

Claude が Fable 5(看板)と Sonnet 5(入口)を同じ月に公開できた一方、OpenAI の GPT-5.6 は限定お試し、Google の Gemini 3.5 Pro は延期でした。この差がそのまま、モデルの実力評価で Claude が先頭に立ち、基盤3社の首位と2位が1点差まで接近した理由になっています。ただ僅差なので、GPT-5.6 の一般開放や 3.5 Pro の公開があれば、また景色が変わりうる流動的な局面です。

### 安く高性能なモデルが「重い層の逃げ道」になった

Claude の Sonnet 5 は、Opus 4.8 級の性能を入力 $2 / 出力 $10 の導入価格で出しました。これが効いていて、重い処理は Sonnet 5 に逃がすという使い分けが現実的な選択肢になったんです。GitHub Copilot も Sonnet 5 のお試し価格や自社系の軽量モデル MAI-Code-1-Flash で、課金反発をやわらげようとしています。「安い高性能モデル」が、値上げ感への構造的な受け皿になりつつあります。

### 企業向けは「エージェントをどう運用するか」が競争軸に

Google が Gemini Enterprise で、エージェントの動きを見張る観測性や統制、承認の仕組みを一気に正式公開しました。GitHub は人とAIが同じ画面で作業する Canvases を、Claude は Slack 連携の Claude Tag を投入。競争の焦点が「モデルの性能」から「エージェントをどう安全に運用し、予算を管理するか」へ広がっています。企業でAIを本番投入する組織なら、選定の基準を性能だけで語れなくなってきた、ということです。

## これから何が起きるか ─ 筆者の見立て

ここからは筆者の推測です。まず、フロンティアの「一般提供」争いが、これからしばらく技術力の順位を左右する主な変数になると見ています。6月は Claude が看板を公開できて先頭に立ちましたが、OpenAI の GPT-5.6 や Google の 3.5 Pro が一般開放されれば、序列はまた動く可能性が高いと感じます。

次に、「安い高性能モデル」がコスパ評価の受け皿として定着しそうです。Claude の Sonnet 5、Copilot 経由の Sonnet 5 お試しや軽量モデルが、値上げ感への緩和策として機能するかが次の焦点になると見ています。企業向けでは、料金の見通しやすさをきちんと解消できた陣営が一歩抜ける展開になりそうです。使った分だけ課金の反発や、使える回数がすぐ尽きる問題は、そのまま選定の分かれ目になると推測されます。

最後に、日本市場では「性能とコストの使い分け」と「予算管理の実務ノウハウ」が定着していくと見ています。日本語での使い勝手では Google AI が先頭ですが、Claude が東京でのイベントの熱量を追い風に、じわじわ距離を詰めていく可能性があると感じます。
